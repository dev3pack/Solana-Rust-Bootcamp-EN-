# ex02 — Functions and Control Flow

**Goal:** write functions with explicit types, return a value from the last
expression, and use `for` and `if`.

## Concepts

- A function signature states the type of every parameter and the return type.
- The last expression without a semicolon is the return value.
- `if` is an expression: it produces a value.
- `for` walks over a collection.
- A slice, `&[u64]`, is a borrowed view of a list of numbers.
- `usize` is the integer type used for lengths and counts.

## What to implement

Open `src/ex02.rs`.

| Function | What it should do |
| --- | --- |
| `base_fee(signatures)` | Return `signatures * 5_000` lamports |
| `total(amounts)` | Add every amount and return the sum; an empty slice sums to zero |
| `count_above(amounts, threshold)` | Count amounts strictly greater than the threshold |
| `clamp_transfer(amount, balance)` | Return the smaller of the two values |

`base_fee` is only the base fee. Solana adds priority fees separately; do not
include them here.

## Worked example

```rust
fn double(n: u64) -> u64 {
    n * 2
}
```

There is no `return` and no semicolon. The expression `n * 2` is the value of
the function. If you write `n * 2;`, the function returns `()` and the compiler
reports a type mismatch.

## Hints

- `for amount in amounts` gives you a reference to each number. Read the number
  with `*amount` when you compare or add it.
- Start `total` with `let mut sum = 0;` and add each amount.
- For `count_above`, start a counter at `0` and increment it inside an `if`.
- `clamp_transfer` can be one `if`/`else` expression: return `balance` when the
  amount is larger, otherwise return the amount.
- The return type `usize` is the type `count` will infer when you return it.

3. summing an empty slice
4. counting strictly above a threshold
