# ex03 — Ownership

**Goal:** see a move happen, take ownership in a function, and return an owned
value.

## Concepts

- Every value has exactly one owner.
- Assigning a `String` moves it; the old binding cannot be used afterwards.
- Passing a `String` to a function moves it into the function.
- Returning a `String` moves ownership back to the caller.
- `&str` is a borrowed string slice. The caller keeps ownership.
- `.to_string()` creates an owned `String` from a `&str`.
- A tuple can return more than one value.

## What to implement

Open `src/ex03.rs`.

| Function | What it should do |
| --- | --- |
| `make_label(owner)` | Take an owned name and return `"account:<name>"` |
| `duplicate(text)` | Return an owned copy of a borrowed string |
| `take_and_return(account)` | Return the account together with its length |
| `consume_all(accounts)` | Consume a `Vec<String>` and return how many names it held |

## Worked example

```rust
let name = String::from("alice");
let moved = name;
// println!("{name}"); // E0382: borrow of moved value
println!("{moved}");   // fine
```

`name` is not a copy of the text. The owner changed. If you need two owners,
you must ask for a clone explicitly:

```rust
let name = String::from("alice");
let copy = name.clone();
println!("{name} {copy}"); // both are valid
```

Cloning is allowed when you genuinely need two owned values. Do not clone only
to silence the compiler; first ask whether a borrow would do.

## Hints

- `format!("account:{owner}")` builds a `String` and moves `owner` into the
  formatting arguments. That is exactly the ownership transfer this exercise
  wants.
- `duplicate` receives a `&str`; call `.to_string()` on it.
- In `take_and_return`, read the length before you return the `String`. Returning
  the tuple moves both values to the caller.
- `consume_all` takes the vector by value. `.len()` borrows it for a moment; the
  vector is dropped when the function ends.

## Tests

`cargo test --test ex03`

There are four tests:

1. a label takes ownership of the name
2. a duplicate is an owned copy
3. an account is returned with its length
4. a vector is consumed
