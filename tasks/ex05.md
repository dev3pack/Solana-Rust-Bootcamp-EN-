# ex05 — Structs and `impl`

**Goal:** group related data in a struct and attach methods to it.

## Concepts

- A struct names a group of fields, and every field has a type.
- `#[derive(Debug, Clone, PartialEq)]` asks the compiler to generate useful
  implementations for you.
- `impl` adds methods to a type.
- `Self` means "the type we are implementing".
- `&self` is a read-only method; `&mut self` may change the value.
- `String::from("system")` creates an owned string.

## What to implement

Open `src/ex05.rs`. The `Account` struct is already defined for you.

| Method | What it should do |
| --- | --- |
| `Account::new(address)` | Create an account with zero lamports and owner `"system"` |
| `deposit(amount)` | Add lamports |
| `withdraw(amount)` | Remove lamports if possible; return `true` on success, `false` otherwise |
| `balance_in_sol()` | Return whole SOL, dropping the remainder |

A failed withdrawal must leave the balance unchanged. Do not subtract first and
then try to undo it.

## Worked example

```rust
struct Point {
    x: i64,
    y: i64,
}

impl Point {
    fn new(x: i64, y: i64) -> Self {
        Self { x, y }
    }

    fn move_right(&mut self, steps: i64) {
        self.x += steps;
    }
}
```

`Self { x, y }` uses field init shorthand: when the variable name matches the
field name, you do not repeat `x: x`.

## Hints

- In `new`, the parameter is already named `address`, so `Self { address, ... }`
  works.
- `deposit` changes `self.lamports`; it needs `&mut self`.
- `withdraw` checks `amount > self.lamports` first. Return `false` immediately
  in that branch.
- `balance_in_sol` is read-only, so it takes `&self`. Divide by
  `1_000_000_000` and return a `u64`.
- This is display-only division. Never store money as a floating-point number.

## Tests

`cargo test --test ex05`

There are five tests:

1. a new account starts empty
2. a deposit adds lamports
3. a withdrawal removes lamports
4. a withdrawal never overdraws
5. the balance is shown in whole SOL
