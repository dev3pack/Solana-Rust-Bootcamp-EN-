# ex04 — Borrowing

**Goal:** lend a value instead of moving it, and change a value through a
mutable reference.

## Concepts

- `&T` is a shared reference: many readers, no writer.
- `&mut T` is a mutable reference: exactly one writer, no readers at the same
  time.
- The golden rule: many `&` **or** one `&mut`, never both.
- A reference never owns the value. The owner keeps it alive.
- Dereference a mutable reference with `*` to change the value behind it.

## What to implement

Open `src/ex04.rs`.

| Function | What it should do |
| --- | --- |
| `total(amounts)` | Read a borrowed slice and return the sum |
| `add_fee(amount, fee)` | Add the fee to the caller's value; return nothing |
| `count_writable(flags)` | Count the `true` values in a borrowed slice |
| `append_note(history, note)` | Push an owned copy of the note onto the caller's history |

## Worked example

```rust
let mut balance = 100;
let fee = 5;

let reader = &balance;   // shared borrow
println!("{reader}");    // last use of the shared borrow
// reader is no longer used after this point

let writer = &mut balance;
*writer += fee;          // change the value behind the reference
```

The shared borrow must be finished before the mutable borrow starts. The
compiler enforces the order.

## Hints

- `for amount in amounts` yields `&u64`. Use `*amount` to read the number.
- `add_fee` must write through the reference: `*amount += fee;`.
- `count_writable` can use `if *flag { ... }`.
- `append_note` receives `&str`; use `note.to_string()` before pushing, because
  the history owns its strings.
- You do not need `.clone()` on the whole vector. Borrow it mutably and push.

## Tests

`cargo test --test ex04`

There are five tests:

1. reading a non-empty slice
2. reading an empty slice
3. a fee changes the caller's value
4. writable accounts are counted
5. a note is appended to the history
